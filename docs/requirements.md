# 要件と実装範囲

添付の「Enterprise XML Visualizer, Comparator & Excel Exporter v3.0」を基準とします。サーバーはIIS静的配信のみ、利用者側でXML解析・比較・出力、外部インターネット不要、日本語UIを主条件とします。

| 機能 | 実装 |
|---|---|
| F01–F05 | 複数ファイル、解析情報、SAX、名前空間付きノード、9ストア、分割保存、残留削除 |
| F06–F07 | 仮想ツリー、詳細、限定断片、D3グラフ、ズーム/パン/方向/画像保存 |
| F08–F13 | A/B切替、3モード、6分類、SHA-256、段階照合、左右差分と左右グラフ |
| F14–F20 | 基準要素選択、列選択、型、繰り返し、条件、プレビュー、制限付きXLSX/逐次CSV |
| F21–F24 | 複数XML統合、差分XLSX、JSONテンプレート、Worker検索 |
| F25–F27 | 構造集計と棒グラフ、分割処理、セキュリティ・無送信 |
| F28–F33 | IIS配布/復旧/検証、Windows手順、機能/性能テスト、処理状態、明示ログ保存 |

大容量や曖昧な照合については「安全な最小実装」を優先します。上表はすべての細目や実機検証の完了を意味しません。機能の具体的な制限はlimitations.md、確認した動作はtest-report.md、実測はperformance-report.mdを正本とします。

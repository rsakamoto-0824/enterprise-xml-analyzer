# 制限と未検証事項

## 安全上の上限

XML全体のサイズではなく、単一トークン1Mi文字、深さ256、名前種類1万、読み込みキュー16ファイルで制限します。ブラウザの保存容量やOSのメモリに依存します。100MB以上で必ず成功する保証はありません。

グラフ500ノード、ツリー表示合計1万ノード、検索保持1万件・移動ボタン100件、差分表示1000行単位。大きな文字値は詳細64Ki文字、Excelセル32767文字、比較詳細4000文字に制限します。

XLSXは5万行・50万セル・1600万文字まで。CSV Blobは32MBまで。File System Access APIの逐次CSV保存にはHTTPSまたはlocalhostが必要です。

## 比較の意味

グローバルな別親への移動判定は行わず、追加・削除として扱います。兄弟4096件を超える場合は暫定対応を曖昧と表示します。XMLの字句表現（実体参照の綴り、引用符の種類等）の比較ではありません。CDATАとtextは別種のノードです。

XPathは子パス・属性・親などの限定構文です。任意のXPath述語・式・XPath 2.0/3.1には対応しません。XML断片は解析結果からの再構成で、元ファイルのバイト列ではありません。

## 検証環境

Windows ServerのIIS実機、AD認証、Windows版Edge、Windows版Excel、UNCアクセス、Windows DPIは、このMacでの自動テストだけでは確認済みにできません。IIS設定XMLの構文・配布物・localhostでの静的配信は確認済みです。実機受入手順はIIS-deployment.mdに記載しています。

## 改善候補

大量の兄弟要素を持つ比較のディスク上キー索引、グローバル移動検出、CSV分割の自動管理、XLSXの真正なブラウザ逐次生成、完全なXPath、XML原文のバイト範囲参照、Windows/IIS CI環境が次の改善候補です。

開発依存にはnpm auditで低リスク4件が残っています。本番依存の指摘は0件でした。E2E実行時のNO_COLOR/FORCE_COLOR警告はテスト出力の色指定に関するもので、アプリの動作エラーではありません。詳細はtest-report.mdを参照してください。

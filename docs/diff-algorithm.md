# XML比較の意味と制限

構造比較は名前空間・ローカル名・属性名・子要素順序を対象にし、値は無視します。値比較は対応要素の属性値・text/cdataノードの値を比較し、対応が得られたノードの順序変更は無視します。存在しない対応要素は値比較でも追加・削除として扱います。完全比較は構造と値の両方を比較します。

属性順序とNamespaceのprefix表記は比較から除外し、URIとlocalNameを識別に使います。Namespace宣言属性そのものは比較対象外です。空白の「無視」は各text/cdataノードのtrimと空白だけのノード除外です。内部の連続空白は折り畳みません。コメント・処理命令は個別に有効化できます。

対応付けは同じ対応親の中で、(1)一意な指定キー属性、(2)一意な名前とサブツリーハッシュ、(3)一意な要素名、(4)兄弟順序で行います。同名の変更された繰り返し要素や重複キーはAMBIGUOUSです。別親への移動は信頼できるグローバル対応を確立できないため追加・削除で表します。MOVEDは同じ親にある一意キーの位置変更です。追加・削除に伴う位置ずれも位置変更として表示されます。

SHA-256へ長さ付きJSONトークンを投入するMerkle方式です。属性はソートし、子ハッシュを順に追加します。構造ハッシュと完全ハッシュを持ちます。比較設定とハッシュの意味が一致する場合だけ省略を許可します。厳密照合を選ぶとハッシュ一致でもノードを走査します。暗号学的ハッシュにも理論的な衝突可能性はあり、数学的な同一性の証明ではありません。

1親あたり4096候補を上限とし、それ以上はページ内の暫定対応としてAMBIGUOUSを示します。総当たり比較は行いません。10分の時間制限、待ち行列10万件の安全制限、中断・途中差分の削除があります。

追加・削除サブツリーと一致サブツリーは1行にまとめる場合があります。coveredはその行が表す文書ノード数です。差分件数はcoveredの合計で、XML要素だけの件数ではありません。表示・出力の値は長さ上限4000文字で、完全な原文保存の代替ではありません。

Enterprise XML Analyzer
Windows版 操作手順書

ZIPを展開したところから、XMLの確認・比較・Excel保存まで。画面と同じ練習用データを使って、一通りの操作を試せます。

対象: Windows x64配布版Pythonの追加インストール不要更新: 2026/10/29
01

Overview

目的と対象

このアプリは、XMLファイルの中身を階層やグラフで確認し、2つのXMLの違いを調べ、必要な項目をExcel・CSVへ取り出すためのデスクトップアプリです。XML原本を直接編集する機能はありません。

見る

構造・値・関連を確認

ツリー、検索、グラフから必要な要素を探します。

比べる

変更前後の違いを確認

構造・値・完全比較を選び、変更箇所へ移動します。

取り出す

すべての項目をExcelへ

縦持ち・横持ちを選び、全要素と属性を保存します。

画面はWindows Server 2022 x64・Python 3.14.6・Tk 8.6.15でアプリを実行して撮影しました。Windows 11／Server 2019は想定対象ですが、会社環境での受入確認は未実施です。画面の配色や文字の大きさはPCの設定で変わります。画像をクリックすると拡大できます。

02

Before You Start

展開したフォルダを確認する

GitHubから取得したファイルがWindows実行版であることを確認します。利用者PCにPythonや開発ツールをインストールする必要はありません。

  1. ダウンロードしたZIPを右クリックし、「すべて展開」を実行します。

    ZIPを開いただけの状態からEXEを実行しないでください。書き込み可能なローカルフォルダへすべて展開します。

  2. 中にもう1つZIPがあれば、そのZIPもすべて展開します。

    GitHub ActionsのArtifactsから取得した場合、外側のZIPに enterprise-xml-analyzer-windows-x64-python3146.zip が入っています。内側のZIPも展開してください。

  3. 次のEXEとフォルダが同じ場所にあることを確認します。

    EnterpriseXmlAnalyzer フォルダの中に入って確認します。

展開後の構成（例）
EnterpriseXmlAnalyzer/
├─ EnterpriseXmlAnalyzer.exe  ← ダブルクリックするファイル
├─ _internal/                ← 実行に必要。EXEと一緒に保管
├─ README-Windows.md
├─ PYTHON-LICENSE.txt
└─ その他の同梱文書・ライセンス
!

EXEだけを移動しないでください

移動する場合は EnterpriseXmlAnalyzer フォルダごと移動します。GitHubの「Code → Download ZIP」で取得するソース一式には、実行用EXEは含まれません。EXEがない場合は配布担当者からWindows実行版を取得してください。

この手順書はPCのEdge・Chrome等で閲覧します。アプリ自体はブラウザやインターネット接続を必要としません。実行対象はWindows x64のデスクトップ環境です。Server Core・32bitは対象外です。

04

Launch

アプリを起動する

  1. EnterpriseXmlAnalyzer.exe をダブルクリックします。

    展開したフォルダ内のEXEを実行します。通常、管理者として実行する必要はありません。

  2. タイトルと「XML読込」画面を確認します。

    「XML読込」「構造ビュー」「グラフ」「XML比較」「Excel出力」「統計」「設定」の7画面があります。ウインドウは最小640×480まで変更でき、幅が狭い場合は上部の「画面」で切り替えます。ボタンは折り返し、縦横のスクロールで操作できます。処理の状況と「中断」ボタンは画面下部にあります。

未署名EXEのためWindowsや会社の管理機能が起動を止める場合があります。会社の実行ルールに従って配布担当者へ確認してください。セキュリティ機能を無効にして実行しないでください。

05

Import

XMLを読み込む

  1. 「XML読込」→「XMLファイルを選択」を押します。

    sample-before.xml と sample-after.xml を選び、「開く」を押します。Ctrlキーを押しながら選ぶと複数選択できます。アプリのウインドウへXMLをドラッグしても読み込めます。

  2. 読込が終わるまで待ち、一覧に2ファイルあることを確認します。

    一覧にファイル名・サイズ・要素数などが表示され、画面下部が「XML読込 · 完了」になります。保持できるXMLは合計16ファイルまでです。

  3. 画面右上で、これから見るXMLを選びます。

    この後の構造表示・検索・グラフは sample-before.xml を選んで進めます。比較とExcel出力はそれぞれのタブでも対象を指定します。

✓

大きなXMLを処理するとき

読込には時間がかかります。処理中は他の操作が一時的に無効になります。中断する場合は画面右下の「中断」を1回押して待ちます。途中でアプリを強制終了しないでください。

06

Structure & Search

構造・検索を確認する

ツリーから1件分のまとまりを探す

  1. 右上で変更前XMLを選び、「構造ビュー」を開きます。

    左の catalog を展開すると、商品1件を表す item が3つ並びます。項目の左の「＋」で子の要素を開きます。

  2. 最初の item をクリックします。

    右側にパスや属性が表示されます。詳細欄が小さい場合は、その中をスクロールして確認します。id="001" が最初の商品です。name は商品名、price は単価、stock は在庫数です。

名前や値で検索する

上部の入力欄へ price を入れ、対象を「要素名」、必要に応じて「完全一致」にチェックし、「検索」を押します。練習用の変更前XMLでは3件が見つかります。下部の検索結果をクリックすると該当要素へ移動します。属性名・属性値・テキスト・パスでも検索できます。

「XML断片を表示」は選択部分のXMLを別画面で確認する機能です。ツリーは必要な部分を順に表示します。非常に大きなデータを一度にすべて開く機能ではありません。

Graph

グラフで見る

「構造ビュー」で item を選び、「選択サブツリーをグラフ表示」を押します。選んだ要素とその子の関係を図で確認できます。

操作使い方
詳細を見るノードをクリックすると構造ビューの詳細へ移動します。
子を開く・閉じるノードをダブルクリックします。
表示位置・大きさドラッグで移動。「拡大」「縮小」またはマウスホイールで倍率を変えます。
図を保存「SVG保存」または「PNG保存」を押し、保存先を選びます。PNGは画面に見えているグラフ範囲を保存します。

グラフは最大500ノード・表示深さ4までの部分表示です。省略表示はXMLの欠落を意味しません。必要な部分を選び直して確認してください。

08

Compare

2つのXMLを比較する

  1. 「XML比較」を開き、XML Aを変更前、XML Bを変更後にします。

    sample-before.xml → sample-after.xml の順に指定します。追加・削除はAからBへの変化として読みます。

  2. 「完全比較」、キー属性 id のまま「比較を開始」を押します。

    キー属性は同じ商品を対応づける目印です。この例では商品IDに相当します。実データでは識別に使う属性名を指定してください。

  3. 結果の絞り込みを「変更」にして、行をクリックします。

    練習用では単価120→150と在庫数12→10の変更を確認します。下部の詳細で変更前後を読み、「Aの要素へ」「Bの要素へ」で実際の要素へ移動できます。

  4. 必要なら「差分XLSX保存」で比較結果を保存します。

    「左右グラフ」では選んだ差分の周辺を並べて確認できます。結果が多い場合は「前の1000件」「次の1000件」でページを切り替えます。

比較モードの選び方
モード主な用途
完全比較構造・属性・値の違いをまとめて確認する。初回はこれを使用します。
構造比較値の変更を除き、要素の構成や並びの違いを調べます。
値比較対応づけられた箇所の属性・テキスト値の違いを中心に確認します。

分類は「追加・削除・変更・移動・変更なし・曖昧」です。「曖昧」は同じキーの重複などで対応を一意に決められない箇所です。親をまたぐ移動は追加・削除として扱います。「空白を除いて比較」「コメントを含む」などの設定は目的に合わせ、比較条件も記録してください。

09

Excel Export

すべての要素をExcelへ出力する

簡単出力：外側のノードを1行にする

v2.5では、プレビュー時に「保存前チェック」も表示します。「作成シート」で全シートの行数・列数、「1行の単位」で実際の要素パスと件数、「ヘッダーの適用範囲」でXML別の適用先を確認してください。未確認の状態や設定変更後に保存を押した場合は先にこの結果を表示します。内容を見てから、もう一度「全要素をExcel保存」を押して保存先を選びます。

シートの行数は見出し行を除きます。列・行のシート分割と、長い値・表示項目の継続行も反映します。横持ちの項目数には元ファイル・ID等3列を含まず、各シートの列数には含みます。縦持ちの中身は11列です。値のプレビューは先頭だけですが、保存前チェックの件数は全件から集計します。

  1. XMLを読み込み、「Excel出力」を開きます。

    最上部の「簡単出力モード（すべての要素・属性）」を使います。読み込み済みの全XMLが対象です。詳細出力の列・条件・XML選択では絞りません。

  2. 「表の形式」で「横持ち」または「縦持ち」を選びます。

    横持ちでは、文書ルート直下の最も外側にあるデータ要素が1行です。指定したヘッダー範囲は除外します。縦持ちはノード・項目名・値を行で並べる一覧です。

  3. 必要なら、下の手順でヘッダー範囲を指定します。

    ヘッダーはロット情報・測定条件などのXML内の情報です。指定要素と配下全体をヘッダー専用シートへ分離し、IDでデータと対応づけます。指定しなければ、各外側要素をデータとして出力します。

  4. 「全要素プレビュー」で確認し、「全要素をExcel保存」を押します。

    「表示する内容」で中身・ヘッダー情報・紐づけ・共通データを切り替えられます。表示は先頭20行・30列・各80文字までですが、保存は全件です。画面下部の完了表示を確認し、保存先のExcelを開きます。

横持ちの1行の単位
XMLの形1行になる範囲
root → record、recordrecordごとに計2行。配下の項目が列になります。
root → header、record、record でheaderをヘッダー指定recordごとに計2行。headerは専用シートへ分離します。
root → data → record、record最も外側のdataで1行。内側のrecordは番号付きの列に展開します。
子要素を持たないrootroot自身で1行。

商品練習用XML2ファイルは、ヘッダー指定なしで横持ち6行・5項目（元ファイル等の列を除く）、縦持ち30行です。文書ルートの直接テキスト2件は共通データに保存し、全26要素・6属性を保持します。

ヘッダー範囲を指定し、データと紐づける

次の練習XMLは共通ヘッダー1件と、データA・Bそれぞれのヘッダーを持ちます。商品練習から切り替える場合は、必要な作業を保存したうえで、「設定」→「すべての作業データと設定を削除」で読み込み済みXMLを消し、このXMLを1つだけ読み込んでください。

ヘッダー付き練習XMLを保存
  1. 「構造ツリーでヘッダーを選択」を押し、headerのチェック欄をクリックします。

    共通の /root/header と、record内の /root/record/header をチェックします。要素を選んでSpace、または右側のチェックボックスでも切り替えられます。同じ要素パスの全出現に適用するため、record内のheaderを1つ選ぶと、データA・Bの両方が対象になります。指定要素は青、配下は薄い青と「配下」の文字で表示されます。後から展開した要素にも反映します。

    「ヘッダーの適用範囲を確認」で出力画面へ戻ります。パスを入力する場合は、従来どおり次の2行を「ヘッダー範囲」に指定できます。複数の範囲が重なった場合は外側にまとめます。親の指定に含まれる子だけを除外することはできないため、範囲を外す場合は親のチェックを解除します。

/root/header
/root/record/header
保存前チェックの切替欄で確認する内容
表示この練習での確認
作成シート横持ちは9シート、縦持ちは8シート。中身・ヘッダー・紐づけ・共通データ等の各行数と列数を確認します。
1行の単位/root/record が2件。横持ちでは2行となり、縦持ちでは同じ基準でデータIDを付け、配下の値を8行へ展開します。
ヘッダーの適用範囲共通headerは該当1件・適用データ2件、record内headerは該当2件・適用データ2件です。対応数はそれぞれ2行、合計4行です。

「該当件数」は定義したパスに一致する要素数、「分離ヘッダー件数」は重複範囲を統合したあとの件数です。同じデータに複数ヘッダーが属すると、適用データ件数より対応数が多くなります。「親範囲に統合」は二重保存を防いだ指定、「該当なし」はそのXMLには対象がない指定です。全XMLで見つからない範囲がある場合は、エラーを確認して指定を修正してください。

  1. 表の形式を選び、「全要素プレビュー」を押します。

    このXMLはデータ2件、ヘッダー3件です。横持ちは2行・4項目、縦持ちは8行です。ヘッダーは両形式とも7項目行の縦持ち一覧として専用シートに保存します。

  2. 「表示する内容」を切り替えて確認します。

    「ヘッダー情報」でロットLOT-001や単位Cを確認し、「紐づけ」で4行の対応を確認します。画面のIDは短縮表示ですが、Excelには完全なIDを保存します。

  3. 「全要素をExcel保存」で保存します。

    「中身のデータ」「ヘッダー」「紐づけ」などのシートを確認します。「簡単出力設定を保存」で形式と範囲をJSONへ保存でき、次回は「簡単出力設定を読込」で再利用できます。設定JSONにXMLの値は含みません。

Excelのシート間で対応をたどる
シート使うID・内容
全要素_横持ち_*／全要素_縦持ちデータIDで中身のデータを識別します。
紐づけデータIDで対応行を探し、その行のヘッダーIDを確認します。1データに複数行が対応する場合があります。
ヘッダーヘッダーIDが一致する全項目行を参照します。ExcelのPower Query等で、データID → 紐づけ → ヘッダーIDの順に結合できます。
データ一覧データIDと元XMLの実際のノード位置の対応です。
共通データ文書ルート自身の直接テキスト・属性です。ファイルIDで、そのXMLの全データに対応します。
ヘッダー定義・項目一覧・出典・出力情報指定範囲、完全な列名、ファイル別の件数、分割や値の扱いを記録します。項目一覧は横持ちだけに作ります。

文書ルートまたはルート直下のヘッダーは、同じXMLの全データへ適用します。データ要素の内側のヘッダーは、そのデータだけへ適用します。異なるXMLや別のrecordへ混ざらないようIDで区別します。指定していないヘッダー名の要素は、通常のデータとして保持します。

親・空要素・全属性・全繰り返しを含め、XMLとして解析後の値をすべて文字列として保持します。先頭ゼロ・大きな数・空白・数式に似た文字列を変換しません。コメント・処理命令・名前空間宣言そのものは値の対象に含みません。

横持ちは元ファイル・ファイルID・データIDの3列と、16381項目ごとに別シートへ分割します。長い値・パスは32767 UTF-16単位で継続欄へ分割します。長い列名は項目一覧で確認できます。全シート合計200万データ行・512シートが上限で、超過・中断・失敗時は既存保存先を保持します。設定は256範囲・JSON 1MiBまでです。印刷時は横に広い表が複数ページに分かれる場合があります。

回帰・分類用に1行の単位を指定する場合：機械学習向け出力

全要素表とは別に、商品1件などの繰り返し要素を1行にする表も作れます。「簡単出力」の下へスクロールし、「機械学習向け出力」を使います。この方式は指定した要素の内側が対象です。

  1. XMLを読み込み、「Excel出力」を開きます。

    一覧の全XMLが対象です。詳細出力の列・条件・対象選択とは独立しています。

  2. 「構造を確認・プレビュー」を押し、1行の単位を確認します。

    全XMLで共通する最も浅い繰り返し要素を自動候補にします。練習用は /catalog/item で、商品1件が1行です。候補を選ぶか要素の絶対パスを入力して変更できます。「XMLファイル単位」なら1ファイルが1行です。変更後は再プレビューしてください。

  3. 必要なら「目的変数」を選びます。

    予測したい項目です。この例で単価の回帰用表を作る場合は price を選びます。分類では分類ラベルの項目を選びます。未指定でも保存でき、あとで学習時に決められます。

  4. 「学習データをExcel保存」を押し、保存先を選びます。

    練習用XML2ファイルでは6件・4項目（@id、name、price、stock）です。画面下部の「学習データ保存 · 完了」を確認します。

機械学習向け出力の4種類のシート
シート内容
学習データ1件1行・1項目1列。選んだ要素配下の値と属性。数値・真偽値は対応するセル型、欠損は空欄です。
出典元ファイルとデータ連番の対応。ファイル名や内部IDを学習列へ自動追加しません。
項目定義全件で判定した型、目的変数、ID候補、欠損数、定数列候補、XML相対パス。
出力情報1行の単位、件数、型と欠損の扱い、学習前の確認事項。

先頭ゼロ、ID候補、15桁を超える数値は文字列で保持します。数値と文字列が混在する列も文字列です。空文字・空白のみ・存在しない項目は空欄になります。子要素の繰り返しは value[1]、value[2] の別列です。候補は構造から選ぶため、1行の意味は利用者が確認してください。

プレビューは全件の型確認後に先頭20件・30項目・各80文字だけ表示します。保存は全件・全項目です。1件1024列・4Mi UTF-16単位、1セル32767 UTF-16単位が上限で、超過時は1行を分割せず保存を中止します。選んだ要素の外側の値が必要なら、行の単位を親へ変更してください。

このアプリはモデル学習・欠損補完・カテゴリ符号化を行いません。ID・定数列・目的変数・欠損を確認し、同じ対象や将来の情報が評価用データへ混ざらないよう分割してください。練習用の変更前後の商品は同一対象なので、機械的にランダム分割する例には使いません。

従来の1要素1行・11列の一覧は「従来の要素一覧を保存（属性をJSONで表示）」で利用できます。練習用2ファイルは26行で、属性はJSONの1欄にまとめます。

必要な列を選びたい場合：詳細出力

① 「1行」の単位を選ぶ

  1. 「構造ビュー」へ戻り、右上を変更前XMLにします。

    検索後は price などが選ばれていることがあります。左のツリーから商品1件を表す item を選び直します。

  2. 「この要素を出力の1行にする」を押します。

    「Excel出力」へ移動し、「1行の基準となる要素パス」が /catalog/item になります。1つの item がExcelの1行になるため、変更前XMLから3行を出力します。

  3. 左上「対象XML」で変更前だけを選びます。

    初期状態では複数のXMLが選ばれていることがあります。この練習では sample-before.xml を通常クリックして1つだけ選択します。複数選択はCtrlキーで操作します。

② 列名と型を整える

候補の列は自動で作られます。表の行をクリックして、その下の「列名」と型を変更し、必ず「列へ反映」を押します。次の4列を順に設定してください。編集欄が見えない場合は、右端の縦スクロールバーで下へ移動します。

練習で使う列設定
相対パス列名型理由
@id商品IDstring001の先頭ゼロを残します。
name商品名string文字列として保存します。
price単価numberExcelで集計できる数値として保存します。
stock在庫数numberExcelで集計できる数値として保存します。

不要な列は「出力ON/OFF」で外し、「上へ」「下へ」で順序を変えられます。繰り返しの初期値 join は複数値を1セルへ結合します。first は最初だけ、rows は行へ展開、sheet は子シートです。初回は初期値のままで構いません。

③ プレビューを確認し、XLSXで保存する

  1. 「プレビュー100行」を押します。

    ボタンが見えない場合は、画面右端の縦スクロールバーで下へ移動します。「先頭3行」と商品ID001・002・003、変更前の単価120・80・350が見えることを確認します。プレビュー欄の中で下へスクロールすると続きの行が見られます。

  2. 「XLSX保存」を押し、保存先とファイル名を指定します。

    例: 商品一覧.xlsx。保存先の選択画面で「保存」を押し、処理の完了を待ちます。プレビュー100行の制限は表示だけで、保存は抽出対象全体に適用されます。

  3. 画面下部の「XLSX保存 · 完了」を確認し、保存先でExcelを開きます。

    ヘッダーに続いて3データ行があり、商品IDの先頭ゼロや数値が正しいことを確認します。SourceFile 列は元のXMLファイル名です。不要なら保存前に「SourceFile」を外します。

✓

複数XMLをまとめる・条件で絞る

対象XMLを複数選び、「1シートに統合」「XMLごとに別シート」「XMLごとに別ファイル」を選べます。最初の練習では「レコード単位」「1シートに統合」「条件なし」のままにします。

条件を試す場合は「抽出条件」の左端へ name、比較方法を equals、その右へ りんご と入力し、「条件追加」→「プレビュー100行」で1行に絞られることを確認します。「条件をクリア」で戻せます。

CSVは「CSV保存」から保存できます。数式のように見える文字列の先頭には安全のためアポストロフィが付きます。先頭ゼロや型を保ちたい場合は、文字列型にしてXLSXで保存してください。CSVは子シート出力に対応しません。

!

作業ファイルと出力設定は別に保存します

作業ファイルはXMLの解析データを保存します。出力列や条件を次回も使う場合は、設定JSONも別途保存してください。作業ファイルを開くと、現在の解析データは置き換わります。

必要な保存が終わったら、ウインドウ右上の「×」で終了します。処理中の場合は中断と後片付けの完了を待ちます。通常終了すると一時作業データは削除されます。明示的に保存したXLSX・CSV・JSON・作業ファイルは残ります。

「すべての作業データと設定を削除」は現在の読込内容・出力設定等を初期化します。ディスクに保存済みのファイルは削除しません。異常終了時には一時フォルダが残る場合があります。

Troubleshooting

困ったとき

EXEが見つからない／Pythonのインストールを求められる

ソース版を取得している可能性があります。enterprise-xml-analyzer-windows-x64-python3146.zip を取得し、外側・内側のZIPをすべて展開します。Windows実行版はPythonを同梱しています。利用者が run.py を直接開く必要はありません。

EXEを開いても起動しない／DLLがないと表示される

ZIP内から直接実行していないか、_internal がEXEと同じ場所にあるか確認します。配布ZIPを新しいローカルフォルダへ再展開して試します。会社の実行制限やウイルス対策による隔離も配布担当者へ確認してください。

Windowsの警告や会社の管理機能で実行が止まる

EXEは未署名です。セキュリティ機能を無効にせず、会社の承認手順に従ってください。管理者権限での実行を標準手順にはしません。

XMLを読み込めない／XML_PARSE・DTD・LIMITなどが表示される

XMLの構文・文字コード・ファイルの読み取り権限を確認します。UTF-8／UTF-16に対応します。DTD・外部実体を含むXMLは受け付けません。深さ256や単一テキスト1Mi文字等の上限に達した場合は、元データの担当者へ相談してください。上限を避けるための無断編集はしないでください。

比較できない／変更が想定と違う／「曖昧」が出る

AとBに異なるファイルを選んでいるか確認します。初回は「完全比較」で試します。キー属性の重複や不足、空白・順序・コメントのオプションでも結果が変わります。画面の設定と対象ファイル名を控え、実際の要素と詳細を確認してください。

Excelの行が多すぎる／少ない／空欄になる

横持ちは文書ルート直下の最も外側の非ヘッダー要素が1行です。商品練習用2ファイルは横持ち6行・5項目、縦持ち30行です。ヘッダー付きXMLはデータ2件・ヘッダー3件です。範囲にルート全体を指定すると、全情報がヘッダーになりデータは0件になります。ヘッダー範囲、表示する内容、共通データのシートを確認してください。

詳細出力の場合は、対象XMLの選択、1行の基準パス、列の相対パス、出力ON/OFF、抽出条件を確認します。練習では変更前だけを選び、/catalog/item を基準にします。パスや列設定は対象XMLの構造に合っている必要があります。

ヘッダー範囲が見つからない／HEADER_PATH・HEADER_NOT_FOUND

要素の絶対パスを1行ずつ指定します。例は /root/header です。[1]、属性、ワイルドカードは指定しません。名前空間付きXMLは構造ビューで要素を選び「構造ビューの選択要素を追加」を使ってください。範囲を変えたら再プレビューします。

列を編集したのに結果へ反映されない

表の該当行を選んで編集し、「列へ反映」を押してから再度プレビューします。プレビューを実行する前の表示は自動更新されません。

「XLSX保存」など下のボタンが見えない

各画面の右端の縦スクロールで下へ移動します。詳細出力の中には別の縦横スクロールもあります。画面幅が狭い場合は上部の「画面」で切り替えます。

「全要素をExcel保存」を押しても保存先の画面が出ない

初回や設定変更後は、先に保存前チェックを作成します。画面に表示された1行の単位・件数・作成シート・ヘッダーの適用先を確認して、もう一度「全要素をExcel保存」を押してください。処理中の場合は完了を待ちます。エラーが出た場合は、ヘッダー範囲の入力内容を確認してください。

保存できない／disk I/O error／処理が遅い

空き容量、保存先への書き込み権限、出力ファイルをExcelで開いたままにしていないかを確認します。大きなXMLは一時作業領域も使用します。共有フォルダで失敗する場合は、許可されたローカルフォルダへの保存を試し、会社の担当者へ権限を確認してください。

全データ削除・終了に時間がかかる

大量データではSQLiteの整理に時間がかかります。中断・終了操作を連打せず待ってください。100万要素後の削除で約1分かかった検証例があります。

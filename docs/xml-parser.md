# XML解析

Saxes 6.0.0のxmlnsモードを使用し、不正な構文は最初のエラーで停止します。UTF-8、UTF-16LE、UTF-16BEを対応対象とし、BOM・先頭バイト・XML宣言を照合します。その他のエンコーディングは明示的なエラーです。UTF-16のサロゲートやUTF-8の多バイト文字がチャンクをまたぐ場合もTextDecoderのstreamモードで復号します。

DTDを一律禁止します。外部エンティティを取得する機構はありません。XML標準の定義済みエンティティ・数値文字参照のみ使用できます。エラーメッセージには入力値を含めず、行・列と分類だけを表示します。

各64KiBの読み取り後にノード・属性・テキストをIndexedDBへ保存して待機します。開いている親要素のフレームだけはメモリ内に保持します。巨大な単一トークンがSAXパーサー内部で増加し続けないよう1Mi文字、階層256、名前種類1万を上限とします。1Mi文字を超える単一テキスト・属性・コメント等は停止対象です。任意の構造を扱いますが無制限ではありません。

途中エラー・利用者中断時には該当fileIdの全ストアを削除します。異常終了による未完成データは次回起動時に削除します。保存領域不足時には専用メッセージを表示します。ブラウザプロセス自体がOSによって終了した場合、同じ画面上でエラー表示する保証はありません。

解析時間は総処理時間からDB書き込み待機時間を差し引いた値、インデックス時間はDB書き込み待機の累計です。CPU時間やDB内部の純粋な索引構築時間ではありません。

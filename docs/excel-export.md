# 抽出・Excel・CSV

標準は繰り返し要素を1行にします。例: 基準 `/Root/Product`、列 `@id`, `Name`, `Price`。名前空間のURIは `{encodeURIComponent(URI)}localName` 形式です。一般XPathではなく、子方向パス、@属性、../親、text()、子ワイルドカードを扱います。

メタデータ列には $name / $path / $namespace / $depth / $file / $attributes、階層展開には $level:0～ を使用します。既定は文字列です。数値変換は明示指定が必要で、安全な整数範囲を超える整数は停止します。日付はYYYY-MM-DDまたはUTC ISO形式、真偽値はtrue/false/1/0です。欠損は空欄またはエラーを選択します。

繰り返しは最初・区切り文字結合・直積の行展開・別シート。行展開は1レコード1万行を上限とし、超える前に停止します。フィルターは完全一致・部分一致・範囲・空欄・存在、AND/ORです。条件評価はWorker内です。

プレビューは先頭100行です。基準ノード数を表示しますが、フィルター後・行展開後の総行数を推測値として断定しません。

「出力書式・安全上限」では保存ファイル名（拡張子なし）、全列共通の列幅、シート名、シート分割行数、ヘッダー、フィルター、固定行を指定できます。列幅は1～100文字相当です。別ファイル出力は連番を付けます。ヘッダーなしの場合も安全側に1048575データ行を上限とします。別シートに繰り返し値を出す場合は、親と子の対応用RecordPath列を追加します。

ExcelJSのブラウザ版はストリーミング書き込みを提供しないため、XLSXを5万行・50万セル・1600万文字に制限します。シート分割の設定はExcelの上限1048575データ行を超えないよう検証します。ヘッダー、フィルター、固定行、幅、日付表示を付けます。1セル32767文字超過は切り捨てず停止します。文字列は文字列型セルとして保存し、数式オブジェクトを作りません。

CSVはUTF-8 BOM、CRLF、全セル引用符、二重引用符エスケープです。先頭空白・制御文字に続く = + - @ を含む文字列にはアポストロフィを加えます。この場合、元の文字列は変更されます。HTTPSのEdgeでFile System Access APIが使えるときは、生成チャンクごとにファイルへ書き込みます。利用できない環境のBlob出力は32MBまでです。中断時はwrite streamをabortします。CSVは1ファイルへ統合し、別シート指定は拒否します。

JSONテンプレートはversion:1。型・列数・フィルター数・シート名・行上限を検証します。XML本体は含みませんが、利用者が設定したパス・列名・フィルター値を含むため、テンプレートの共有範囲には注意してください。

参考: [ExcelJS Browser](https://github.com/exceljs/exceljs#browser)。Microsoft Excel実機での再オープン検証は受入手順で実施してください。ライブラリによる再読込成功だけでExcel実機互換性を確認済みとは扱いません。

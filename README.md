# Enterprise XML Analyzer — Pythonスタンドアローン版

Windowsの実行環境の違いに対応するため、主なアプリをPython 3.14.6のデスクトップ版へ作り直しました。XMLの階層表示・グラフ・比較・項目抽出・XLSX/CSV出力を、PC内で実行します。

**実行時の追加pipパッケージは0件です。** Windows配布版はPython 3.14.6本体とTcl/Tk等を同梱し、ブラウザ、Node.js、IIS、インターネット接続を必要としません。

## Windowsで起動

**v2.5.1では、ドラッグ＆ドロップ直後にアプリが終了する不具合を修正しました。** 修正版ZIPは旧版とは別のフォルダへすべて展開して、EXEを起動してください。Windowsの通知処理ではファイル名の受け取りだけを行い、画面と読み込みの処理は通常のイベント処理へ渡します。

Windows x64用の `enterprise-xml-analyzer-windows-x64-python3146.zip` をすべて展開し、`EnterpriseXmlAnalyzer/EnterpriseXmlAnalyzer.exe` を起動します。`_internal` フォルダを削除・移動しないでください。

ソース版は、CPython **3.14.6完全版（Tcl/Tk付き）** で起動します。別のバージョンでは起動を止めます。

```bat
py -3.14 run.py
```

または `start_windows.cmd` をダブルクリックします。Pythonのembeddableパッケージは通常Tkinterを含まないためソース版の実行には使いません。詳しい手順は [Windows操作・配布ガイド](docs/python-windows.md) を参照してください。

## 使い方

### 簡単出力モード（外側ノード単位・ヘッダー分離、v2.5）

XMLを読み込み、「Excel出力」の最上部で **横持ち** または **縦持ち** を選びます。**全要素プレビュー** で確認し、**全要素をExcel保存** を押します。読み込み済みの全XMLが対象で、詳細出力の列・条件・XML選択では絞り込みません。

**保存前チェック**には、中身の行数・列数・作成シート数を表示します。切替欄で「作成シート」の全シート名と行数・列数、「1行の単位」の実際の要素パスと件数、「ヘッダーの適用範囲」のXML別の件数を確認できます。シートの行数は見出し行を除き、Excel上限によるシート分割と長い表示項目の継続行を含みます。横持ちの項目数と、元ファイル・ID等を含む各シートの列数は区別します。設定が未確認の場合や変更後に保存を押した場合は、まず確認結果を表示するので、内容を見てから再度保存を押します。

| 形式 | 中身のデータの形 |
|---|---|
| 横持ち | 文書ルート直下の最も外側のデータ要素＝1行。指定したヘッダー範囲は除外し、配下の全項目を列へ展開 |
| 縦持ち | ノード・項目名・値・データIDなどを並べ、要素の直接テキストと属性をそれぞれ1行に出力 |

例えば `<root><header>共通情報</header><record>データA</record><record>データB</record></root>` で `/root/header` をヘッダーに指定すると、横持ちはrecordごとの2行です。子要素のないXMLでは文書ルート自身を1行にします。ルート直下にさらにコンテナがある場合は、そのコンテナが1行となり、内側の繰り返しは列に展開されます。

**ヘッダー範囲**には要素の絶対パスを1行ずつ指定します。指定した要素と配下全体を「ヘッダー」シートへ分離します。「構造ビュー」で対象要素を選び、「構造ビューの選択要素を追加」でも指定できます。範囲を重ねて指定した場合は、外側の範囲に統合して二重出力を防ぎます。どのXMLにも見つからない範囲は、エラーとして保存を止めます。名前空間付きの要素は選択要素からの追加を利用してください。

**構造ツリーの「ヘッダー」欄をクリックするか、要素を選んでSpaceを押しても指定できます。** チェックした要素は青、その配下は薄い青と「配下」の表示になります。同じ要素パスの全出現・全XMLに適用し、後から展開した要素にも反映します。色だけでなくチェック文字でも状態を区別します。「ヘッダーの適用範囲を確認」で、XMLごとの該当件数・分離ヘッダー件数・共通／ノード内の適用範囲・適用データ件数・対応数を確認できます。1データに同じ範囲のヘッダーが複数ある場合、適用データ件数と対応数は異なります。親範囲に統合された指定や、一部XMLに該当しない指定も表示します。

```text
/root/header
/root/record/header
```

- **ヘッダー**：両形式とも、ヘッダーID付きの縦持ち一覧です。上記の1行目は同じXMLの全データに適用し、2行目はそれぞれのrecordだけに適用します。
- **紐づけ**：データIDとヘッダーIDの対応表です。1データに複数のヘッダーを関連付けられます。中身のデータ → データIDで紐づけ → ヘッダーIDでヘッダーを結合できます。
- **データ一覧**：データIDと元XMLの実際のノード位置を記録します。
- **共通データ**：文書ルート自身の直接テキスト・属性を保持します。ファイルIDで、そのXMLの全データに対応します。
- **項目一覧**（横持ち）：完全な列名とデータシート・Excel列の対応。**出典・ヘッダー定義・出力情報**にも設定と出力件数を記録します。

「表示する内容」で中身・ヘッダー・紐づけ・共通データのプレビューを切り替えます。画面のIDは短縮表示ですが、Excelには完全なIDを保存します。「簡単出力設定を保存／読込」で形式とヘッダー範囲を再利用でき、XMLの値は設定JSONに含みません。設定は256範囲・JSON 1MiBまでです。

親・空要素・全属性・繰り返しを保持し、値は数値も文字列のまま保存します。先頭ゼロ・大きな数・空白・数式に似た文字列を変換しません。外側の行を区別する番号はデータ一覧に保存し、内側の繰り返しは `[1]`、`[2]` の列にします。異なる種類の外側要素も、それぞれの行と列に出力します。

横持ちは元ファイル・ファイルID・データIDの3列に加え、16381項目ごとに別シートへ分けます。長い列名は短縮し、完全な名前を項目一覧に保存します。1セル32767 UTF-16単位を超える値・パスは継続列／行へ分割して保持します。プレビューは先頭20行・30列・各80文字までですが、保存は全件です。全シート合計200万データ行・512シートの安全上限超過・中断・失敗時は保存を中止して既存ファイルを保持します。

商品練習用XML2つをヘッダー指定なしで出力すると、横持ちは6行・5項目（元ファイル等を除く）、縦持ちは30行です。文書ルート2つの値は共通データに保存され、全26要素・6属性を保持します。ヘッダー付き練習用XMLでは、横持ち2行・4項目／縦持ち8行、ヘッダー3件・7項目行、紐づけ4行です。

### 機械学習向け出力（1行の単位を指定）

XMLを読み込み、「Excel出力」で **構造を確認・プレビュー** を押します。全XMLで共通する最も浅い繰り返し要素を自動候補とし、利用者が1行の単位を変更できます。必要なら予測したい項目を「目的変数」に選び、**学習データをExcel保存** を押します。XMLファイル単位（1ファイル＝1行）にも切り替えられます。

- **学習データ**：選んだ要素1件を1行、配下の値・属性を1項目1列に展開。子要素の繰り返しは `[1]`、`[2]` の別列です。
- **出典**：ファイル名とデータ連番の対応。ファイル名・内部ID・パスを学習列へ自動追加しません。
- **項目定義**：全件で判定した型、目的変数、ID候補、欠損数、定数列候補、XML相対パス。
- **出力情報**：1行の単位、件数、欠損・型の扱い、学習前の確認事項。

数値・真偽値は対応するセル型で出力し、ID候補・先頭ゼロ・15桁超の数値は文字列として保持します。欠落・空文字・空白だけの値は空欄です。全件で数値と文字列が混在する列は文字列に統一します。自動補完・行削除・モデル学習は行いません。目的変数の指定は項目定義に記録され、列の削除や符号化は行いません。学習前にID・定数列・欠損・同一対象や時系列のデータ漏洩を確認してください。

選んだ要素の外側の値は含みません。必要なら行の単位を親へ変更します。1件1024列・文字量4Mi UTF-16単位、1セル32767 UTF-16単位が上限です。超過時は行を分割せず保存を中止します。シートは1048575データ行で分かれ、補助シートを含む合計200万行が安全上限です。

従来の親・空要素を含む一覧は、**従来の要素一覧を保存（属性をJSONで表示）** で利用できます。こちらは1要素1行・11列で、長い値を継続行へ分割します。簡単出力・機械学習向け出力・従来の要素一覧は読み込み済みの全XMLが対象で、詳細出力の列・条件・対象選択を変更しません。

### ウインドウのサイズ変更

最小640×480に対応します。幅が狭い場合は上部の「画面」で7画面を切り替えます。ツールバーは折り返し、各画面の縦スクロールと表・詳細設定の横スクロールで操作できます。入力内容と読み込み済みXMLはサイズ変更後も保持します。

### 詳細出力・比較

[スクリーンショット付きHTML操作手順書](docs/python-user-guide/procedure-guide.html) を用意しています。Windows配布版では `UserGuide/procedure-guide.html` をブラウザで開いてください。練習用XMLも同梱しています。HTML単体版と手順書ZIPは `python scripts/package_user_guide.py` で作成できます。

1. 「XML読込」でXMLを選択、またはウインドウへドロップします。
2. 「構造ビュー」で繰り返し要素を選び、「この要素を出力の1行にする」を押します。
3. 「Excel出力」で列を選び、型・繰り返し・条件を設定します。列の編集後は「列へ反映」で確定します。
4. プレビュー後にXLSXまたはCSVを保存します。複数XMLの統合・別シート・別ファイルにも対応します。
5. 「XML比較」でA/Bを選び、構造・値・完全の比較を実行できます。

通常終了時は一時作業データを削除します。残す場合は「設定」から作業ファイルを明示的に保存します。詳細な制限とデータの扱いは [設計・安全制限](docs/python-design.md) に記載しています。

## 構成

`run.py` が起動入口、`xml_analyzer/` が画面・解析・SQLite・比較・抽出・逐次出力、`tests_python/` が機能とGUIのテストです。実行環境の固定は `.python-version` と `pyproject.toml` の両方に記載しています。環境変数・APIキーの設定は不要です。

旧Web版の `src/`、npm設定、IIS/Electron資材は移行履歴として保持しています。Python版の実行・配布には含めません。[旧版README](docs/legacy-web-readme.md) と旧版の性能報告を、Python版の動作保証として使わないでください。

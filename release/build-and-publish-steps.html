Operating Guide · Internal Use

Enterprise XML Analyzer
操作手順書

この手順書では、XML解析アプリの導入・更新・復旧と項目抽出を安全かつ確実に完了するための操作を説明します。

対象: IIS管理者・XML利用者 配信方式: 社内IIS / HTTPS 更新日: 2026/10/18
01

Overview

目的と対象

XMLの構造表示・比較・必要項目のExcel出力を行います。IISは静的ファイルを配信し、XMLの内容は利用者のPC内で処理します。

対象はWindows Server 2019以降のIIS 10とWindows版Edgeです。サーバーにNode.js・Python・DBは不要です。Windows/IIS実機の受入検証は導入担当者が実施してください。

02

Prerequisites

作業前の確認

  • 配布ZIPを管理用フォルダへ展開し、wwwrootとdeploymentを確認する。
  • 専用の公開フォルダ、HTTPS証明書、利用者の認証・アクセス権をIIS管理者が用意する。
  • 更新時は利用者に作業の保存を依頼し、公開先の外にバックアップを置く。
  • 会社の作業でCodex・Claude Codeは不要。PowerShellとIISマネージャーで導入する。
03

Workflow

全体の流れ

1配布物を確認ハッシュと配置先
→
2DryRun書き込み前の確認
→
3配備バックアップとコピー
→
4検証EdgeとExcelで確認
04

Procedure

操作手順

開発端末でビルド

npm ci
npm test
npm run build

artifacts/enterprise-xml-analyzer-iis.zipを社内サーバーへ移します。インターネット接続は開発時の依存取得にのみ必要です。

IISへ初回配備・更新

cd C:\Deploy\XmlAnalyzer\deployment
.\deploy.ps1 -Source ..\wwwroot -Destination C:\inetpub\xmlviewer -BackupRoot C:\Deploy\XmlAnalyzerBackups -DryRun
.\deploy.ps1 -Source ..\wwwroot -Destination C:\inetpub\xmlviewer -BackupRoot C:\Deploy\XmlAnalyzerBackups
.\verify-deployment.ps1 -Url https://internal-server/xmlviewer/

IISでサイト直下または仮想ディレクトリ/xmlviewer/に公開先を割り当てます。URL末尾に/を付けます。公開するのはwwwrootの中身だけです。IIS全体の再起動は行いません。

XMLを利用

  1. XML読込

    ファイルをドロップ、または選択します。複数ファイルは16件まで同時に選択できます。

  2. 構造を選択

    構造ビューで繰り返し要素を選び、「この要素を出力の1行にする」を押します。

  3. 抽出して保存

    出力列・型・繰り返しを指定し、100行のプレビュー後にXLSXまたはCSVを保存します。

  4. 比較

    XML比較でA/B・モード・キー属性を選択します。曖昧な対応は紫のラベルで表示します。

直前の版へ復旧

.\rollback.ps1 -Backup C:\Deploy\XmlAnalyzerBackups\20261018-150000-000 -Destination C:\inetpub\xmlviewer -SafetyBackupRoot C:\Deploy\RollbackSafety -DryRun

バックアップ時刻は実際のフォルダ名に置換します。確認後は-DryRunを外して実行し、verify-deployment.ps1を再実行します。

05

Verification

完了確認

  • HTTPSのURLが開き、認証対象者だけが利用できる。
  • XML読込、ツリー展開、検索、グラフ、比較、Excel保存が動く。
  • 開発者ツールでXML送信・外部ホストへの通信が発生しない。
  • Windows版Excelで修復警告なしに開け、行数・先頭ゼロ・文字列・日付を確認できる。
  • 終了前に設定画面から作業データを削除できる。
  • 100MB合成XML、125%/150%の表示、UNCの手動ファイル選択を確認する。
06

Troubleshooting

困ったとき

IISで500.19になる

web.configの設定ロック、機能の未導入、親サイトの設定を確認します。設定を一括解除せず、IIS管理者へ依頼してください。

Excel出力の上限に達した

XLSXは5万行・50万セル・1600万文字までです。抽出範囲を絞るか、HTTPSのEdgeでCSV逐次保存を使用してください。

解析が途中で停止する

構文エラー、UTF-8/UTF-16以外、DTD、深さ256超過、単一トークン1Mi文字超過、ストレージ不足を確認します。不完全な解析結果は削除されます。

別タブで使用中と表示される

同じアプリを開いているタブを閉じてから再読込してください。同一ブラウザ内の同時タブによる削除競合を防いでいます。

詳しい制限と実測結果は同梱docsフォルダのlimitations.md、test-report.md、performance-report.mdを確認してください。
